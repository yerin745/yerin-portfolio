# 개인 포트폴리오 웹사이트

교재의 실습 흐름에 맞춰 HTML, CSS, 바닐라 JavaScript로 제작한 반응형 포트폴리오입니다.

## 실행 방법
1. ZIP 파일의 압축을 풉니다.
2. `index.html`을 더블 클릭해 브라우저에서 엽니다.
3. Cursor 또는 VS Code에서 작업한다면 폴더를 열고 Live Server로 실행할 수 있습니다.

## 수정하면 좋은 항목
- `index.html`의 간단한 자기소개 문구 (개인 정보는 필요한 만큼만 기재)
- 프로젝트 카드의 제목과 설명, 실제 작업 이미지/링크
- 연락 이메일: iyelini@gmail.com
- 페이지 제목과 하단 연도

## 구성
- `index.html`: 페이지 구조와 콘텐츠
- `styles.css`: 색상, 레이아웃, 반응형 디자인
- `script.js`: 모바일 메뉴, 스크롤 진행 표시, 섹션 애니메이션, 연락 폼

※ 프로젝트 소개는 예시 문구입니다. 제출 전 본인이 실제로 수행한 작업과 결과물에 맞게 수정하세요.
※ 연락 폼은 기본 메일 앱을 여는 데모 방식이며, 서버로 메시지를 저장하지 않습니다.
